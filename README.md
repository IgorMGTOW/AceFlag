# AceFlag
iOS/iPadOS Application that displays the asexual pride flag (ace flag) onto the screen. Runs via Xcode and or Altstore/Sidestore Sideloading as an .ipa (though I did not test sidestore).

This Project was created back in 2024 and was inspired from NCommanders progress-pride-win16 project, although without using any of the code from it, and I wanted to make my own project for iOS and iPadOS.

The code in this project is provided as-is and no future updates or support is guaranteed.
